# 网页使用

Speakr 的顶层入口是 **会议记录、声音工作室、实时对话**。会议内的 **文字记录、实时摘要、完善纪要、Todo** 是同一条记录的不同视图。

| 目标 | 入口 | 保存对象 |
| --- | --- | --- |
| 留下语音想法或会议内容 | 会议记录 → 文字记录 | 转写文字、标题、标签 |
| 总结与修改表达 | 实时摘要 / 完善纪要 | 摘要正文与完善对话 |
| 整理可执行计划 | 摘要下方“转为 Todo” | Markdown Todo 与完善对话 |
| 让文字变成声音 | 声音工作室 | 本次试听/下载结果，不建立生成历史 |
| 与语音模型交流 | 实时对话 | 对话文字记录 |

## 选择存储方式

- **账号模式**：使用受邀账号，记录由服务器同步，其他账号不能读取。
- **访客模式**：记录保存在当前浏览器 IndexedDB；刷新后重新选择访客模式即可读取本浏览器历史。清除浏览器数据会删除这些记录。

账号与访客记录不会自动互相迁移。浏览器发给 ASR 和文本模型的处理请求不等同于建立长期录音档案，见[数据保留边界](recording-storage.md)。

## 录音与转写 {#recording}

1. 新建会议，确认设置中的识别通道可用。
2. 点击录音并允许浏览器使用麦克风。远程访问应使用 HTTPS。
3. 暂停时等待当前识别片段提交；继续录音后文字仍归入本条会议。
4. 结束后等待最后一段识别完成，再检查转写和摘要。

可修改会议标题、手动刷新标题、添加标签，并从历史列表打开记录。复制文字只复制转写，不导出原始音频。清空、新建或删除活动会议会中断当前录音资源，应先确认内容是否需要保留。

## 摘要与完善纪要 {#summary}

- **实时摘要**显示生成结果，支持主动更新和复制。
- **完善纪要**提供可编辑画布和对话框，可描述受众、强调重点、整理行动项或检查遗漏。
- 手动或对话定制后的纪要不会因继续录音而被自动摘要覆盖；主动重新生成仍应检查结果。
- 对话改写失败或流未完整结束时，保留原纪要。撤销按钮恢复最近一次模型修改前的正文。

标题与纪要可以使用不同文本模型，配置缺失不会靠语音密钥补齐。

## Markdown Todo {#todo}

摘要下方点击 **转为 Todo**，进入独立 Todo 页面。也可以先打开空 Todo 页，自己写 Markdown，再通过对话完善。

Todo 的正文和对话不与原摘要混写。它支持复制、`.md` 下载，以及把 `- [ ]` 改为 `- [x]` 标记完成；当前是文本编辑器，不是思维导图。[完整 Todo 流程](markdown-todo.md)。

## 声音工作室 {#studio}

系统音色和“我的复刻声音”共用一个文本输入区域。系统音色由服务端配置动态提供，支持页面中的 MP3/WAV 选择。选择复刻声音后，上传或录制参考音频并确认声音授权，再生成试听结果。

系统 TTS 与声音复刻是不同后端。一项不可用，不代表另一项也不可用；页面应显示具体配置或连接状态。[声音复刻指南](voice-cloning.md)。

## 实时对话 {#realtime}

选择服务端允许的实时模型和音色后开始对话。完成后可查看、保存和导出对话文字。当前实时代理面向 Qwen 实时音频接口，并非任意文本模型都能替换。

模型出现在列表中、连接成功或收到会话开始事件，都不代表账户有生成权限。遇到额度/未购买错误，应修正账户权限或套餐，不自动切换按量服务。
