# Markdown Todo

先讨论想法，再决定是否把它变成行动。Todo 是一份独立的 Markdown 正文，不是自动任务执行器。

| 你想做什么 | 操作 |
| --- | --- |
| 从已有摘要得到行动计划 | 摘要下方点击“转为 Todo” |
| 先保留空页或自己写 | 打开 Todo 标签并直接编辑 |
| 拆步骤、调整顺序、补完成标准 | 在 Todo 对话区提出要求 |
| 恢复模型改写前的内容 | 点击撤销修改 |
| 交给其他工具处理 | 复制 Markdown 或导出 `.md` |

## 显式转换

1. 生成或完善当前会议摘要。
2. 判断这份想法值得推进后，点击摘要下方 **转为 Todo**。
3. 检查生成的分组、任务和子步骤；负责人、时间或承诺不能凭空补造。

打开 Todo 标签和刷新摘要不会自动转换。已有 Todo 再次从摘要生成时会先确认替换，原正文可在当前页面撤销。原会议摘要与转写保持不变。

## 编辑与继续对话

左侧是 Markdown 文本编辑器，右侧是专属于这份 Todo 的完善对话。例如：“把第一项拆成三个可执行步骤”“按依赖顺序整理”“保留已完成项”。模型返回完整正文和简短修改说明。

```markdown
# 技术文章

## 准备
- [x] 确认主题
- [ ] 整理核心结论与出处

## 撰写
- [ ] 写出初稿
  - [ ] 确定段落结构
  - [ ] 补充示例
- [ ] 检查引用后发布
```

将 `- [ ]` 改为 `- [x]` 表示完成。撤销按钮针对当前页面保留的模型改写/重新生成历史；不要把它当作跨设备完整版本库。

取消、请求失败或晚到的旧结果不会覆盖手工编辑后的正文。没有明确行动时可以保留无待办状态，不必强行凑任务。

## 保存、导出与边界

- Todo 和完善对话随对应会议保存；账号模式使用服务器，访客模式仅当前浏览器。
- **复制 Markdown** 与 **导出 .md** 提供普通文本，可供后续其他工具使用。
- 当前不包含思维导图、外部任务平台同步、提醒或自动执行。
- 模型使用当前会议纪要配置；无需新密钥。转换时发送摘要，完善时发送摘要、当前 Todo 和相关对话。

接口与字段 `todo_markdown`、`todo_chat_messages` 见 [HTTP 接口](api-access.md#todo)。
