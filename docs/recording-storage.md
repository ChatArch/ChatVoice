# 数据保留边界

“保存会议记录”指保存文字与元数据，不是保存原始录音文件。

| 数据 | 账号模式 | 访客模式 |
| --- | --- | --- |
| 标题、标签、转写 | 服务器 SQLite，按账号隔离 | 当前浏览器 IndexedDB |
| 摘要与纪要完善对话 | 随会议保存 | 随本地会议保存 |
| Markdown Todo 与完善对话 | 随会议保存 | 随本地会议保存 |
| 实时对话文字 | 随对话记录保存 | 当前浏览器保存 |
| 原始会议录音 | 不建立音频档案 | 不保存录音分片档案 |
| 模型服务密钥 | 仅服务端配置 | 不发送到浏览器 |

## 处理不等于归档

麦克风音频会经过浏览器、ChatVoice 和所选 ASR 服务。服务端可能使用 `temp/asr` 中的临时文件解码和识别，正常处理后清理。外部 ASR/文本模型服务的数据政策由其提供者决定。

因此，“不保留会议录音”不代表音频完全不经过网络或磁盘，也不代表访客转写可以离线运行。

## 声音工作室的输出

系统 TTS 和声音复刻会生成当前任务的音频，供试听/下载；这不是会议录音下载。声音复刻需要本人授权的参考音频，不建立可复用音色库或生成历史。离开会话后，不应把临时参考音频当作永久资产。

## 删除与备份

- 清除浏览器数据会删除访客记录；登录不会自动上传这些记录。
- 删除服务器记录需账号所有权与 CSRF 校验。
- 已经导出的 Markdown、数据库备份或第三方保存的副本需要分别管理。
- 代码回滚不应恢复旧数据库并覆盖新增记录。
